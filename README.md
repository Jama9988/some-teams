## Requirements

- The data you will be using is in [data.php](resources/data.php).

- Your web site should contain a start page and an about page.

- The about page should have information about you, the creator.

- Both pages of the web site should use a common header. The start page should display the teams listed in [data.php](./resources/data.php). Feel free to list them how you like.

- If you want to, you can add a dynamic third page, that shows info about the team you clicked on in the list.

- If you want to, you can add CSS to mark the teams that will drop out of the tournament (as some of them will during week 40).

- The project should not print (echo) any HTML within PHP strings.

- The project should not include any coding errors, warning or notices.
- The repository should be public and have at least 7 commits and **not just one big commit**.

- The repository should contain a [`README.md`](https://guides.github.com/features/mastering-markdown/) file with information about the project (usually a README.md includes information about what the project is about, how it's made, about the author, install instructions if any and such stuff)

- The repository should contain a [`LICENSE`](https://help.github.com/articles/open-source-licensing) file. Preferably MIT. Add your full name.

## Coding Standards

The code should have [consistent syntax](https://www.php-fig.org/psr/psr-12) including correct indentation, [readable](https://github.com/jupeter/clean-code-php#introduction) and well documented code.

If your Visual Studio Code doesn't already [automagically](https://giphy.com/gifs/harry-potter-hermione-granger-the-deathly-hallows-PcfozPlZSzARO) format your PHP code when you save a file, you can add the configuration below to your `settings.json` file.

```json
"[php]": {
    "editor.defaultFormatter": "bmewburn.vscode-intelephense-client"
}
```
