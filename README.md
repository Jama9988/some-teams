# Some Teams

## About the Project

Some Teams is a PHP website that displays teams participating in a women's football tournament. The start page lists the teams and their leagues, and the About page introduces the creator.

This project was created as part of a web development course to practise PHP, HTML, CSS, and Git.

## Technologies Used

- PHP
- HTML5
- CSS3
- Git and GitHub

## Project Structure

- `index.php` — The start page, displaying the participating teams.
- `about.php` — The About page with information about the creator.
- `header.php` — Shared header and navigation links.
- `css/style.css` — Stylesheet for the website.
- `resources/data.php` — Team data used by the website.

## How to Run the Project Locally

1. Install PHP on your computer.
2. Open a terminal in the project folder.
3. Start the PHP development server by running:

   ```bash
   php -S localhost:8000
   ```

4. Open `http://localhost:8000/index.php` in your browser.
5. Use the navigation links to visit the Home and About pages.
